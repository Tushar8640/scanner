# ডকুমেন্ট স্ক্যানার অ্যাপ: সফটওয়্যার রিকোয়ারমেন্টস স্পেসিফিকেশন (SRS)

- **ভার্সন:** 0.1
- **তারিখ:** 2026-11-07
- **স্ট্যান্ডার্ড:** IEEE 830 / ISO/IEC/IEEE 29148

---

## ১. ভূমিকা (Introduction)

### ১.১ উদ্দেশ্য (Purpose)
এই স্পেসিফিকেশনের উদ্দেশ্য হলো একটি আধুনিক, প্রাইভেসি-ফার্স্ট ডকুমেন্ট স্ক্যানার মোবাইল অ্যাপ্লিকেশনের কার্যকারিতা, স্থাপত্য, গুণগত মান এবং সীমাবদ্ধতা সুস্পষ্টভাবে নির্ধারণ করা। প্রতিটি রিকোয়ারমেন্ট আইডির (Requirement ID) বিপরীতে টেস্ট কেস তৈরি ও ভেরিফিকেশন করা হবে।

### ১.২ পরিধি (Scope)
- ক্যামেরা দিয়ে উচ্চমানের ডকুমেন্ট স্ক্যান, প্রান্ত শনাক্তকরণ (Edge detection) ও perspective correction।
- ক্রপ সমন্বয় এবং বিভিন্ন প্রাক-নির্ধারিত ফিল্টার (Original, Grayscale, B&W, Enhanced) প্রয়োগ।
- একক বা একাধিক পেজ মিলিয়ে মানসম্মত PDF ও JPEG এক্সপোর্ট ও শেয়ার।
- অফলাইন ডকুমেন্ট ব্যবস্থাপনা (ফোল্ডার, সার্চ, সর্টিং)।
- অন-ডিভাইস OCR (ইংরেজি প্রাথমিক, পরবর্তীতে বাংলা)।
- নিরাপত্তা ও গোপনীয়তা (স্থানীয় স্টোরেজ, বায়োমেট্রিক/পিন লক, কোনো ব্যাকএন্ড সার্ভার বা ক্লাউড সিঙ্ক নেই)।

### ১.৩ পরিধির বাইরে (Out of Scope)
- কোনো ক্লাউড সিঙ্ক বা অনলাইন সার্ভার ডাটাবেস।
- ব্যবহারকারী অ্যাকাউন্ট/লগইন ব্যবস্থাপনা।
- একাধিক ব্যবহারকারীর কোলাবোরেশন বা রিয়েল-টাইম শেয়ারিং।
- ওয়েব বা ডেস্কটপ সংস্করণ।
- তৈরি করা PDF ফাইলের মধ্যকার টেক্সট সরাসরি এডিটিং।

### ১.৪ অগ্রাধিকার স্কিম (Priority Scheme - MoSCoW)
- **Must:** MVP (Minimum Viable Product)-এর জন্য বাধ্যতামূলক।
- **Should:** MVP-তে থাকা উচিত; সময় কম থাকলে পরবর্তী তাৎক্ষণিক রিলিজে।
- **Could:** পরবর্তী সংস্করণে (Phase 2 / V2) যুক্ত হবে।
- **Won't:** বর্তমান বিবেচনায় রাখা হচ্ছে না।

## ২. সামগ্রিক বিবরণ (Overall Description)

### ২.১ মূল পার্থক্যকারী বৈশিষ্ট্য (Differentiators)
1. **১০০% অন-ডিভাইস ও প্রাইভেসি-ফার্স্ট:** ব্যবহারকারীর কোনো ডকুমেন্ট কখনো কোনো দূরবর্তী সার্ভারে আপলোড হয় না।
2. **বাংলা ও স্থানীয় প্রেক্ষাপট:** স্বতঃস্ফূর্ত বাংলা ইউজার ইন্টারফেস এবং বাংলা যুক্তাক্ষর সমর্থিত OCR সহায়তা।
3. **ওয়াটারমার্ক-মুক্ত ফ্রি সংস্করণ:** ক্যামস্ক্যানার বা অন্যান্য বাণিজ্যিক অ্যাপের মতো ফ্রি ডকুমেন্টে কোনো অনাকাঙ্ক্ষিত ওয়াটারমার্ক বা বিজ্ঞাপন থাকবে না।

### ২.২ ব্যবহারকারী শ্রেণি (User Classes)
| শ্রেণি | সাধারণ কাজ | মূল চাহিদা |
|---|---|---|
| **শিক্ষার্থী** | লেকচার নোট, অ্যাসাইনমেন্ট স্ক্যান | একসাথে অনেক পেজ স্ক্যান, ছোট ফাইল সাইজ |
| **অফিস কর্মী** | চুক্তিপত্র, রসিদ, অফিসিয়াল ফর্ম স্ক্যান ও দ্রুত শেয়ার | ডিজিটাল স্বাক্ষর, হাই-কোয়ালিটি PDF |
| **সাধারণ ব্যবহারকারী** | জাতীয় পরিচয়পত্র (NID), পাসপোর্ট, সার্টিফিকেট | ID কার্ড মোড (২ পিঠ এক পেজে), পাসওয়ার্ড প্রটেকশন |
| **ক্ষুদ্র ব্যবসায়ী** | ইনভয়েস, বিল ভাউচার সংগ্রহ ও সংরক্ষণ | ফোল্ডার অর্গানাইজেশন, সার্চ, OCR টেক্সট কপি |

### ২.৩ অপারেটিং এনভায়রনমেন্ট (Operating Environment)
- **Android:** Android 7.0 (API 24)+; Google Play Services সহ (ML Kit Scanner-এর জন্য নূন্যতম ১.৭ জিবি র‍্যাম)।
- **iOS:** iOS 13+ (দ্বিতীয় পর্যায়ে একই কোডবেস থেকে)।
- **ফ্রেমওয়ার্ক:** React Native (New Architecture - Fabric & TurboModules)।
- **নেটওয়ার্ক:** সম্পূর্ণ অফলাইন (ML Kit মডেল ডাউনলোডের ক্ষেত্রে প্রথমবার ইন্টারনেটের প্রয়োজন হতে পারে)।

### ২.৪ সীমাবদ্ধতা ও নির্ভরতা (Constraints & Dependencies)
- স্ক্যানিং স্ক্রিনের জন্য Google ML Kit Document Scanner API ব্যবহার করায় এর সিস্টেম ক্যামেরা UI সরাসরি কাস্টমাইজযোগ্য নয়।
- Google Play Services বিহীন ডিভাইসের জন্য গ্যালারি ইমপোর্ট ও বিকল্প ক্রপ পাথ নিশ্চিত করা।
- ভারী ইমেজ প্রসেসিং ও PDF তৈরির প্রক্রিয়া নেটিভ থ্রেডে পরিচালনা করতে হবে।

## ৩. কার্যকরী রিকোয়ারমেন্টসমূহ (Functional Requirements)

### ৩.১ স্ক্যানিং (Scanning)
- **FR-01 [Must]:** ক্যামেরা দিয়ে এক বা একাধিক পেজ ধারাবাহিক স্ক্যান করা।
- **FR-02 [Must]:** স্বয়ংক্রিয় ডকুমেন্ট কিনারা শনাক্তকরণ ও perspective correction।
- **FR-03 [Must]:** ম্যানুয়ালি চার কোণা টেনে ক্রপিং সমন্বয়।
- **FR-04 [Must]:** গ্যালারি থেকে বিদ্যমান ছবি ইমপোর্ট করে ডকুমেন্ট হিসেবে রূপান্তর।
- **FR-05 [Should]:** এক সেশনে সর্বোচ্চ পেজ সংখ্যা কনফিগারেশন (ডিফল্ট: ৫০ পেজ)।
- **FR-06 [Should]:** ID Card Mode: আইডি কার্ডের উভয় পিঠ স্ক্যান করে একটি একক পেজে সংস্থাপন।
- **FR-07 [Could]:** Play Services বিহীন ডিভাইসে ম্যানুয়াল ক্রপসহ বিকল্প ফলব্যাক পাথ।

### ৩.২ পেজ এডিটিং ও প্রসেসিং (Editing & Processing)
- **FR-10 [Must]:** ইমেজ ফিল্টার: Original, Grayscale, Black & White (B&W/Document Clean), Enhanced/Bright।
- **FR-11 [Must]:** প্রতিটি পেজ ৯০ ডিগ্রি করে ডান/বামে ঘোরানো (Rotate)।
- **FR-12 [Must]:** পেজের ক্রম পুনর্বিন্যাস (Reorder), পেজ মোছা (Delete), এবং অতিরিক্ত পেজ যুক্ত করা (Add Page)।
- **FR-13 [Should]:** ম্যানুয়াল ব্রাইটনেস ও কনট্রাস্ট অ্যাডজাস্টমেন্ট স্লাইডার।

### ৩.৩ PDF ও এক্সপোর্ট (PDF & Export)
- **FR-20 [Must]:** স্ক্যান করা একাধিক পেজ একত্র করে একটি সিঙ্গেল PDF ফাইল তৈরি।
- **FR-21 [Must]:** স্ট্যান্ডার্ড পেজ সাইজ নির্বাচন: A4, US Letter, অথবা ছবির মূল সাইজ (Fit to Image)।
- **FR-22 [Must]:** কম্প্রেশন কোয়ালিটি নির্বাচন: Low (স্মল সাইজ), Medium (স্ট্যান্ডার্ড), High (হাই রেজোলিউশন)।
- **FR-23 [Should]:** প্রতিটি পেজকে স্বতন্ত্র JPEG ছবি আকারে এক্সপোর্ট।
- **FR-24 [Should]:** স্ট্যান্ডার্ড পাসওয়ার্ড সুরক্ষিত (AES এনক্রিপ্টেড) PDF তৈরি।
- **FR-25 [Could]:** ডকুমেন্টের পেজে ডিজিটাল স্বাক্ষর (Signature Overlay) যোগ করা।
- **FR-26 [Could]:** একাধিক বিদ্যমান PDF ফাইল জোড়া লাগানো (Merge PDF)।

### ৩.৪ ডকুমেন্ট ব্যবস্থাপনা (Document Management)
- **FR-30 [Must]:** হোম স্ক্রিনে ডকুমেন্টের তালিকা (থাম্বনেইল, শিরোনাম, তৈরির তারিখ, পেজ সংখ্যা)।
- **FR-31 [Must]:** অর্থবহ স্বয়ংক্রিয় শিরোনাম তৈরি (যেমন: `Doc_YYYYMMDD_HHmm`) এবং রিনেম করার সুবিধা।
- **FR-32 [Must]:** নিশ্চিতকরণ বার্তা (Confirmation Dialog) সহ ডকুমেন্ট মোছার সুবিধা।
- **FR-33 [Should]:** ফোল্ডার তৈরি, নাম পরিবর্তন এবং ডকুমেন্টস নির্দিষ্ট ফোল্ডারে সরানো।
- **FR-34 [Should]:** ডকুমেন্টের নাম এবং OCR টেক্সট অনুসারে দ্রুত গ্লোবাল সার্চ।
- **FR-35 [Should]:** নাম, তৈরি বা পরিবর্তনের তারিখ অনুযায়ী ডকুমেন্ট সাজানো (Sort A-Z, Date Asc/Desc)।
- **FR-36 [Could]:** ট্র্যাশ ক্যান (Trash Bin): ডিলিট করা ফাইল ৩০ দিন সংরক্ষণ ও রিকভারি।

### ৩.৫ টেক্সট রিকগনিশন (OCR)
- **FR-40 [Should]:** অন-ডিভাইস ইংরেজি টেক্সট এক্সট্রাকশন এবং ক্লিপবোর্ডে কপি করার সুবিধা।
- **FR-41 [Could]:** বাংলা টেক্সট এক্সট্রাকশন (Tesseract বা সমন্বিত অফলাইন ইঞ্জিন)।
- **FR-42 [Could]:** এক্সট্রাক্ট করা টেক্সট `.txt` ফাইল আকারে শেয়ার বা সংরক্ষণ।
- **FR-43 [Could]:** সার্চযোগ্য (Searchable PDF with Invisible Text Layer) রূপান্তর।

### ৩.৬ শেয়ার ও এক্সপোর্ট (Share & Storage)
- **FR-50 [Must]:** সিস্টেম শেয়ার শীট (Android Intent / iOS Share Sheet) দিয়ে যেকোনো অ্যাপে শেয়ার।
- **FR-51 [Must]:** ডিভাইসের পাবলিক ফোল্ডারে (Downloads / Documents) সরাসরি সেভ।
- **FR-52 [Could]:** সিস্টেম প্রিন্ট সার্ভিসের মাধ্যমে সরাসরি ওয়্যারলেস প্রিন্ট।

### ৩.৭ নিরাপত্তা ও প্রাইভেসী (Security & Privacy)
- **FR-60 [Should]:** বায়োমেট্রিক (Fingerprint / Face ID) অথবা ৪-সংখ্যার PIN অ্যাপ লক।
- **FR-61 [Could]:** সংবেদনশীল নির্দিষ্ট ফোল্ডারের জন্য পৃথক লক সিস্টেম।

### ৩.৮ সেটিংস ও স্থানীয়করণ (Settings & Localization)
- **FR-70 [Must]:** পূর্ণাঙ্গ বাংলা ও ইংরেজি ইউজার ইন্টারফেস (ডিফল্ট: সিস্টেম ভাষা)।
- **FR-71 [Should]:** ডিফল্ট ফিল্টার, পেজ সাইজ এবং এক্সপোর্ট কোয়ালিটি প্রিসেট সেটিং।
- **FR-72 [Should]:** ডার্ক মোড এবং লাইট মোড থিম সাপোর্ট (সিস্টেম ফলোয়িং বা ম্যানুয়াল)।

### ৩.৯ প্রিমিয়াম ও মানিটাইজেশন (Monetization & Future)
- **FR-80 [Could]:** ইন-অ্যাপ পারচেজ বা ওয়ান-টাইম লাইফটাইম লাইসেন্স।
- **FR-81 [Could]:** প্রিমিয়াম ফিচার: আনলিমিটেড ব্যাচ OCR, পাসওয়ার্ড প্রটেকশন, কাস্টম সিগনেচার।
- **FR-82 [Must]:** **ফ্রি সংস্করণে ডকুমেন্টের উপর কোনো ওয়াটারমার্ক থাকবে না।**

## ৪. অ-কার্যকরী রিকোয়ারমেন্টসমূহ (Non-Functional Requirements)

- **NFR-01 (Performance):** কোল্ড স্টার্ট সময় ≤ ২ সেকেন্ড (মাঝারি মানের ৩ জিবি র‍্যামের ফোনে)।
- **NFR-02 (Performance):** স্ক্যানার ইন্টারফেস সক্রিয় হতে সময় ≤ ১.৫ সেকেন্ড।
- **NFR-03 (Performance):** ১০ পেজের মাঝারি কোয়ালিটির PDF জেনারেশন ≤ ৫ সেকেন্ড।
- **NFR-04 (Storage Efficiency):** মাঝারি কোয়ালিটিতে প্রতি পেজের আউটপুট সাইজ ≤ ৪০০ KB।
- **NFR-05 (UI Smoothness):** ৫০০+ ডকুমেন্টের তালিকা ফ্লুইড ৬০ FPS স্ক্রলিং।
- **NFR-06 (Bundle Size):** প্রোডাকশন রিলিজ APK সাইজ ≤ ৩০ MB (প্রতি আর্কিটেকচার)।
- **NFR-10 (Privacy):** ব্যবহারকারী কোনো থার্ড-পার্টি অ্যাপে শেয়ার না করা পর্যন্ত ডাটা অ্যাপের স্যান্ডবক্সের বাইরে যাবে না।
- **NFR-20 (Security):** সমস্ত স্ক্যান ও প্রসেস করা ফাইল অ্যাপের প্রাইভেট ডিরেক্টরিতে সংরক্ষিত থাকবে।
- **NFR-21 (Security):** পিন হ্যাশ Android Keystore বা iOS Keychain-এ সুরক্ষিত থাকবে।
- **NFR-31 (Usability):** প্রতিটি টাচ টার্গেট নূন্যতম 48 × 48 dp আয়তনের হবে।
- **NFR-33 (Localization):** বাংলা যুক্তাক্ষর এবং ফন্ট রেন্ডারিং যথাযথ ও ত্রুটিহীন হতে হবে।
- **NFR-50 (Code Quality):** TypeScript Strict Mode, ESLint, Prettier এবং ক্লিন আর্কিটেকচার অনুসরণ।

## ৫. ডেটা মডেল ও আর্কিটেকচার (Data Model & Architecture)

### ৫.১ রিলেশনাল স্কিমা (SQLite)

```sql
CREATE TABLE folders (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    parent_id TEXT NULL,
    is_locked INTEGER DEFAULT 0,
    created_at INTEGER NOT NULL
);

CREATE TABLE documents (
    id TEXT PRIMARY KEY,
    folder_id TEXT NULL,
    title TEXT NOT NULL,
    page_count INTEGER NOT NULL DEFAULT 0,
    pdf_path TEXT NULL,
    thumbnail_path TEXT NOT NULL,
    ocr_text TEXT NULL,
    deleted_at INTEGER NULL,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL,
    FOREIGN KEY(folder_id) REFERENCES folders(id) ON DELETE SET NULL
);

CREATE TABLE pages (
    id TEXT PRIMARY KEY,
    document_id TEXT NOT NULL,
    position INTEGER NOT NULL,
    original_path TEXT NOT NULL,
    processed_path TEXT NOT NULL,
    filter TEXT CHECK(filter IN ('original', 'grayscale', 'bw', 'enhanced')) DEFAULT 'enhanced',
    rotation INTEGER CHECK(rotation IN (0, 90, 180, 270)) DEFAULT 0,
    ocr_text TEXT NULL,
    FOREIGN KEY(document_id) REFERENCES documents(id) ON DELETE CASCADE
);
```

### ৫.২ ফাইল সিস্টেম লেআউট

```
<app-private-storage>/
  └── documents/
      └── {document_id}/
          ├── original/
          │   ├── {page_id_1}.jpg
          │   └── {page_id_2}.jpg
          ├── processed/
          │   ├── {page_id_1}.jpg
          │   └── {page_id_2}.jpg
          ├── thumb.jpg
          └── export.pdf
```
